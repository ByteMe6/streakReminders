# streakReminders

Track daily habits with streaks — like Duolingo, but for anything you want to build consistency on.

**[Live Demo](https://byteme6.github.io/streakReminders/)** · [Русский](./README.ru.md)

## Features

- Create and track named streaks
- Streak counter increments each time you check in
- Add and delete streaks
- Email/password authentication (Firebase Auth)
- Data stored per user (Firebase Realtime Database)
- Toast notifications

## Tech

- Vanilla JavaScript
- Firebase Auth + Realtime Database
- Toastify

## Setup

No bundler required — open `index.html` directly or serve with any static file server.

Firebase config is already embedded in `firebase.js`. To use your own project, replace the config there.
